母ちゃんの脳トレ道場 — PWA版

1. ZIPを展開します。
2. 既存のGitHub Pagesを更新する場合は、展開したファイルを現在の
   index.htmlがある公開フォルダにまとめて置き、同名のファイルを上書きします。
   新しく公開する場合は、同じ公開フォルダに6つのアプリ用ファイルを置きます。
   このREADMEは公開フォルダに入れなくても動作します。
3. 公開が反映されたら、AndroidのChromeでHTTPSの公開URLをオンラインで開きます。
4. Chromeの「︙」から「ホーム画面に追加」または「アプリをインストール」を選びます。
   「ホーム画面に追加」の中に「インストール」がある場合はそちらを選びます。
5. 初回は通信できる状態でアプリを開きます。ホームから一度起動したあと、
   機内モードにして開き直すとオフライン起動を確認できます。

現在と同じ公開URLを使うと、同じブラウザに保存されたレベルと中断データを
引き続き利用できます。ZIPを展開して直接index.htmlを開く方法ではなく、
公開URLからインストールしてください。
