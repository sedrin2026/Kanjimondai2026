# 母ちゃんの漢字道場（初期版）

## 同梱ファイル
- index.html : 画面
- app.js : ゲーム処理
- questions.json : 4ジャンル各100問、合計400問
- manifest.webmanifest : ホーム画面追加用設定
- sw.js : オフライン用キャッシュ

## ゲーム仕様
- レベル0～100。正解1問で1レベル上昇。
- 不正解でレベル0に戻る。
- 10レベル帯ごとに、その帯の10問からランダム出題。帯内の出題済み問題は一巡するまで避ける。
- 問題ジャンルは4種類。ホーム画面からジャンル別、または全ジャンル混合で開始できる。
- レベルは端末内のlocalStorageに保存。

## GitHub Pagesで公開してオフライン利用
1. GitHubで新しいRepositoryを作る。
2. このZIPの中身をすべてリポジトリ直下へアップロードする。
3. Settings → Pages → Deploy from a branch → main / root を選んで保存。
4. 表示されたGitHub PagesのURLをスマホChromeで開く。
5. 初回は通信が必要。ページを最後まで読み込んでから、Chromeメニューの「ホーム画面に追加」を選ぶ。
6. 一度開いた後は、Service Workerが画面・問題データをキャッシュするので、通信なしでも起動できる。

※AndroidのChromeではHTTPSで配信されたページでService Workerが利用できます。index.htmlをファイルアプリから直接開く方法ではオフラインキャッシュは有効になりません。

## APKについて
この一式はまずオフライン対応PWAとして動く構成です。APK化は別工程です。Android StudioまたはBubblewrap等のAndroidビルド環境が必要です。スマホとGitHubだけで進める場合は、GitHub Actionsを使ってAPKをビルドするワークフローを追加できますが、Android署名キーなどの設定が必要になります。まずGitHub PagesでPWAの動作を確認してからAPK化するのが安全です。

## 初期版の注意点
- 鳥アイコンは動作確認用の絵文字仮素材です。ご希望の高品質な鳥・鳳凰イラストは、段階ごとの画像素材を追加して差し替える次工程です。
- 背景・文字サイズ・4択画面はスマホ向けに大きくしています。
- 歴史問題には発明・科学・日本史・世界史の基礎問題を含みます。公開前に、問題文や選択肢の表現を最終確認してください。
